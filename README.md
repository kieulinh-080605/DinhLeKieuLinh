# DinhLeKieuLinh_DiemDanh

App Điểm Danh Cho Sinh Viên - Đồ án Android Jetpack Compose

## Thông tin
- **Package:** `com.dinhlekieulinh.diemdanh`
- **Công nghệ:** Kotlin, Jetpack Compose, Material 3, MVVM, Retrofit + OkHttp, Navigation Compose
- **Base URL:** `http://10.0.2.2:5000/api/` (tự động fallback Mock data khi chưa có server)

## Cách chạy
1. Mở Android Studio → nhấn **Load Gradle Project**
2. Chờ Sync Gradle hoàn tất
3. Chọn Emulator → nhấn ▶️ Run

## Tài khoản Demo
- Tại màn hình đăng nhập, nhấn nút chip **Admin** / **Giảng viên** / **Sinh viên**
- Mã OTP demo: `123456`
